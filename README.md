# 🔥 Fire Storm

> Your Personal Developer LMS – Track. Visualize. Conquer.

---

## 🚀 Overview

**Fire Storm** is a personal LMS-style tracker built for developers who want to monitor their daily progress in **LeetCode, DSA, and Web Development**. Inspired by modern learning portals, Fire Storm helps maintain consistency through clean visuals, streak tracking, and project logging.

Designed with the motivation to **build discipline, showcase learning, and gamify progress**.

---

## 🎯 Features

- 📅 **Daily Streak Tracker** for LeetCode & Coding Practice  
- 🧠 **Coding Logs** with DSA topics, languages, and difficulty levels  
- 🌐 **Web Development Tracker** – HTML, CSS, JS, React journey  
- 📊 **Progress Visualizations** – Weekly/monthly charts, streak heatmap  
- 🏆 **Achievements System** – Unlock badges and celebrate milestones  
- 🗂️ **Project Log** with GitHub integration  
- 🌓 **Dark/Light Mode** support  
- 📱 **Mobile Responsive UI**

---

## 🛠️ Tech Stack

| Layer        | Tools/Tech Used              |
|-------------|------------------------------|

| **Backend**  | Supabase / Firebase (optional) |
| **Styling**  | Tailwind CSS / Custom CSS |
